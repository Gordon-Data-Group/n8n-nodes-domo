# n8n-nodes-domo

This is an n8n community node. It lets you use Domo in your n8n workflows. This is not supported by Domo and is an unofficial node.

Domo is a cloud-based business intelligence and data experience platform that connects to virtually any data source, centralizes it, and provides interactive dashboards, real-time insights, and collaboration tools.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/reference/license/) workflow automation platform.

## Usage

Some operations require knowledge of the API JSON structure Domo uses to create or update objects. You will be required to enter relevant JSON for the following objects and the relevent operations. This can be found by inspecting network traffic as you perform operations in Domo. Example placeholders are given when possible.

- Dynamic Groups
- Dataset Accounts
